齐次坐标

使用齐次坐标的目的之一是表示无穷点。

在欧几里得坐标系中，无穷点是不存在的。但是如果使用无穷的概念，许多几何概念和计算可以大大简化。当我们进行曲线和表面设计时，这一点更加明显。

假设有两个实数，aaa 和 www，计算 aw\frac{a}{w}wa​ 的值。

我们保持 aaa 的值不变，改变 www 的值。随着 www 变得越来越小，aw\frac{a}{w}wa​ 的值变得越来越大。如果 www 接近零，aw\frac{a}{w}wa​ 就会接近无穷大！

因此，为了表示无穷大的概念，我们使用两个数 aaa 和 www 来表示一个值 vvv，v=awv=\frac{a}{w}v=wa​。如果 www 不为零，那么该值就是 aw\frac{a}{w}wa​。否则，我们用 (a,0)(a,0)(a,0) 来表示无穷大的值。因此，无穷大的概念可以用 (a,w)(a, w)(a,w) 或者 aw\frac{a}{w}wa​ 来表示。

让我们把这个方法应用到xyxyxy坐标系上。如果我们使用xw\frac{x}{w}wx​和yw\frac{y}{w}wy​替换xxx和yyy，那么函数f(x,y)=0f(x,y)=0f(x,y)=0就变成了f(xw,yw)=0f(\frac{x}{w},\frac{y}{w})=0f(wx​,wy​)=0，将它与系数wnw^nwn的数相乘就可以消除掉所有分母，其中nnn是多项式的次数。

例如，假设我们有一条线 Ax+By+C=0Ax + By + C = 0Ax+By+C=0。将 xxx 和 yyy 替换为 xw\frac{x}{w}wx​ 和 yw\frac{y}{w}wy​ 得到 A(xw)+B(yw)+CA(\frac{x}{w}) + B(\frac{y}{w}) + CA(wx​)+B(wy​)+C = 0。乘以 www 会变为

Ax+By+Cw=0Ax + By + Cw = 0 Ax+By+Cw=0

给定方程为二次多项式 Ax2+2Bxy+Cy2+2Dx+2Ey+FAx^2 + 2Bxy + Cy^2 + 2Dx + 2Ey + FAx2+2Bxy+Cy2+2Dx+2Ey+F = 0。在将 xxx 和 yyy 替换为 xw\frac{x}{w}wx​ 和 yw\frac{y}{w}wy​ 并乘以 w2w^2w2 后，我们得到

Ax2+2Bxy+Cy2+2Dxw+2Eyw+Fw2=0Ax^2+2Bxy+Cy^2+2Dxw+2Eyw+Fw^2=0 Ax2+2Bxy+Cy2+2Dxw+2Eyw+Fw2=0

如果你仔细观察这两个多项式，你会发现所有项的次数是相等的。在直线的情况下，项xxx、yyy 和 www 的次数都是一次，而在二次多项式中，所有项(即x2x^2x2，xyxyxy，y2y^2y2，xwxwxw，ywywyw 和 w2w^2w2)的次数都是二次。

给定一个nnn次多项式，在引入www后，所有的项都是nnn次的。因此，这些多项式被称为齐次多项式，而坐标(x,y,w)(x,y,w)(x,y,w)则被称为齐次坐标。

给定一个在齐次坐标系统中的nnn次多项式，将该多项式除以wnw^nwn，然后将xw\frac{x}{w}wx​和yw\frac{y}{w}wy​分别替换为xxx和yyy，将会将该多项式转换回常规形式。例如，如果给定的3次齐次多项式如下所示：

x3+3xy2−5y2w+10w3=0x^3 + 3xy^2 - 5y^2w + 10w^3 = 0 x3+3xy2−5y2w+10w3=0

经过转换后，结果是

x3+3xy2−5y2+10=0x^3 + 3xy^2 - 5y^2 + 10 = 0 x3+3xy2−5y2+10=0

这个规则也适用于三维。可以将点(x,y,z)(x, y, z)(x,y,z)替换为(xw,yw,zw)(\frac{x}{w}, \frac{y}{w},\frac{z}{w})(wx​,wy​,wz​)，并将结果乘以www的某个幂。所得的多项式是齐次的。

一个重要的说明

给定一个齐次坐标系中的点(x,y,w)(x,y,w)(x,y,w)，它在xyxyxy平面上对应的点是什么？根据前面的讨论，很容易得到，是(xw,yw)(\frac{x}{w},\frac{y}{w})(wx​,wy​)。
因此，一个在齐次坐标系中的点(3,4,5)(3,4,5)(3,4,5) 转换为xyxyxy平面上的点为(3/5,4/5)=(0.6,0.8)(3/5,4/5)=(0.6,0.8)(3/5,4/5)=(0.6,0.8)。
同样，一个在齐次坐标系中的点(x,y,z,w)(x,y,z,w)(x,y,z,w)转换为空间中的点为(x/w,y/w,z/w)(x/w,y/w,z/w)(x/w,y/w,z/w)。
相反，xyxyxy 平面上一点 (x,y)(x,y)(x,y)的齐次坐标是什么？简单地说就是 (x,y,1)(x,y,1)(x,y,1) 。即 www 分量为 1。
xyxyxy 平面上一点 (x,y)(x,y)(x,y) 的齐次坐标是 (xw,yw,w)(xw, yw, w)(xw,yw,w)，其中 www 是任意非零数。

我们有结论：
将齐次坐标转换为常规坐标是唯一的；但是，将常规坐标转换为齐次坐标则不是。

例如，空间中的点 (4,2,3)(4,2,3)(4,2,3) 转换成齐次坐标为 (4w,2w,3w,w)(4w, 2w, 3w, w)(4w,2w,3w,w), 其中www为非零值，可以有无数种可能。

无穷远点

设一个点坐标为(x,y)(x,y)(x,y)，通过乘以1w\frac{1}{w}w1​转换为齐次坐标，即(xw,yw,1w)(\frac{x}{w},\frac{y}{w},\frac{1}{w})(wx​,wy​,w1​)。

当www的值接近于零时，点(xw,yw)(\frac{x}{w},\frac{y}{w})(wx​,wy​)就会朝着(x,y)(x,y)(x,y)的方向越来越远。当www变为零时，点(xw,yw)(\frac{x}{w},\frac{y}{w})(wx​,wy​)就移动到了无穷远处。

因此，我们可以说，齐次坐标(x,y,0)(x,y,0)(x,y,0)是指向(x,y)(x,y)(x,y)方向的无穷远点。

(3,5)是xyxyxy平面上的一个点。考虑点(3w,5w)(\frac{3}{w},\frac{5}{w})(w3​,w5​)，该点是直线 O+dwO + \frac{d}{w}O+wd​上的一个点，其中OOO是坐标原点，ddd是方向向量<3,5><3,5><3,5>。因此，当www趋近于零时，该点在直线上无限远处。

对于空间中的点也是一样的，(x,y,z,0)(x, y, z, 0)(x,y,z,0)是指向(x,y,z)(x, y, z)(x,y,z)方向的无穷远点。
